# 图标资源来源

本项目所有应用 UI 图标均来自微软官方开源图标库 **Microsoft Fluent UI System Icons**，
没有再手工编写任何 SVG 路径 / Slint Path / 字符或 Emoji 图标。

| 项 | 值 |
| --- | --- |
| 上游仓库 | https://github.com/microsoft/fluentui-system-icons |
| 引用 | `main` |
| 解析到的提交 | `e15fc0de25fab983e3e42bac8798be69a85c23bf` |
| 许可证 | MIT（见同目录 LICENSE） |
| 规格 | 24px 画布（1 个图标因上游无 24px 版本改用其它尺寸，见下表画布列）；Regular 为默认态，Filled 为选中态 |
| 抓取时间 | 2026-11-09 15:03:59 |

## 关于 colorize

Slint 的 `Image.colorize` 把图像当作 **alpha 蒙版** 并以给定颜色绘制（见 i-slint-compiler
`builtins.slint` 中 `Image.colorize` 的文档），因此本目录的 SVG 保持微软原始字节不变，
主题色 / 选中态 / 禁用态着色全部在 Slint 侧完成，无需为每种颜色生成副本。
